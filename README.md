# CMPSC132-Final-Project

The project I chose to complete was the 3rd option given to me, which was the Number Guessing Game, a single player, terminal based game. The computer generates a random number, and I chose to have it generate a number from 1 to 100. The player has different numbers of attempts to guess this number, based on the difficulty level they choose. If they choose hard, they will have 3 attempts max. If they choose medium, they will have 6 attempts max. Finally, if they choose easy, they will have 10 attempts max. The game provides feedback to the player for every guess, indicating whether their guess or either too high or too low. Each game will end once the player guesses the correct number, or the player uses up all of their attempts. 

Instructions to run the program:
1. Please indicate whether or not you would like to start playing the game. The game will start if and only if you type "Yes".
2. Please choose your difficulty level. You have 3 options.
3. Please guess a random number. The computer will give you feedback.
4. If you run out of attempts or you guess the correct number, the game will end.
5. Indicate whether or not you would like to continue playing.
